e-BK Career Self-Efficacy – Prototype
=========================================
Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder.
3. Klik dua kali index.html.
4. Pilih akses Siswa atau Guru BK.
5. Masukkan nama demo lalu klik Masuk.

Fitur:
- Login demo dua peran
- Asesmen Career Self-Efficacy 10 item skala 1–5
- Hasil skor dan interpretasi awal
- Materi karier
- Symbolic Modeling (slot untuk video alumni)
- Career Challenge
- Pengajuan konseling/bimbingan daring
- Refleksi
- Evaluasi layanan
- Dashboard Guru BK
- Etika dan privasi

Catatan penting:
Ini prototype akademik. Data tersimpan secara lokal di browser (localStorage) dan belum cocok untuk data konseli nyata.
Untuk implementasi sekolah perlu backend/database aman, autentikasi, kontrol akses berbasis peran, enkripsi, audit log, kebijakan retensi data, serta SOP layanan BK digital.
